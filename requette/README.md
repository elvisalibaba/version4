# Requettes Supabase

Ce dossier garde les requettes SQL a executer dans Supabase quand une fonctionnalite demande une modification de base.

Pour les profils auteurs publics ajoutes ici, le schema actuel contient deja `author_profiles`, les champs utiles et les policies publiques de lecture. Le fichier `001_profils_auteurs_publics.sql` sert surtout de verification et de correctif si une base Supabase n'a pas encore les policies ou index attendus.
