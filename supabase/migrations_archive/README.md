# Archive des migrations d'avant la baseline

Ces fichiers sont l'historique des changements appliqués avant le 14/10/2026. Ils ont été appliqués à la main (éditeur SQL), ou enregistrés sous d'autres numéros de version.

L'état réel de la base à cette date est décrit par `supabase/migrations/20261014090000_baseline_schema.sql`.

**Ne jamais les rejouer.** La CLI Supabase ne lit pas ce dossier. Voir `docs/supabase-migration-repair-plan.md`.
