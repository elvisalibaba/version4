# HolisticBooks Design

Ce document adapte le système visuel OAMedKit/OpenAfya à HolisticBooks sans reprendre l’identité médicale.

## Principes

- Fond principal : #FAFAFA
- Couleur primaire : #0879D9
- Bleu sombre : #1459B8
- Bleu clair : #349AF0
- Texte principal : #17171A
- Texte secondaire : #4D4D53
- Surface champs : #F0EEF0
- Bordure légère : #D9D9DE
- Largeur maximale du contenu : 430 px
- Padding horizontal : 16 px
- Boutons : 42 px, rayon 21 px
- Champs : 52 px, rayon 8 px
- Titres principaux : 28 px, graisse 800
- Corps : 13 px

## Navigation mobile

Navigation persistante à quatre destinations :
1. Accueil
2. Découvrir
3. Bibliothèque
4. Profil

## Composants partagés

- AppColors
- AppDimensions
- AppLogo
- AppButton
- AppTextField
- AuthBackground
- AppShell

Toute nouvelle interface mobile HolisticBooks doit réutiliser ces composants et tokens avant d’introduire une nouvelle valeur locale.
